# 海战棋主题设计稿

本目录保留本轮评审的三套配色设计稿，便于后续追溯和继续迭代：

- `option-1.png`：方案 1
- `option-2.png`：方案 2
- `option-3-selected.png`：方案 3「雾与信号」，本次选定并实现

## 已选方案 3

主题支持三种偏好：

- `自动`：跟随操作系统的浅色 / 深色外观
- `白天`：雾蓝背景、暖白面板、深蓝文字和信号色
- `夜晚`：暖石墨背景、深灰面板、粉蓝文字和信号色

核心色板：

| 语义 | 白天 | 夜晚 |
| --- | --- | --- |
| 页面背景 | `#BCCDD3` | `#161616` |
| 面板 | `#E8ECEB` | `#232322` |
| 抬升表面 | `#F3F3EF` | `#2D2D2B` |
| 棋盘格 | `#CEDBDD` | `#343736` |
| 主文字 | `#24353C` | `#EEECE5` |
| 次文字 | `#65777D` | `#A5A49E` |
| 主信号色 | `#315F78` | `#86AFC2` |
| 命中 | `#D75C4D` | `#EF6A59` |
| 击沉 | `#C8933E` | `#D6A14D` |
| 分隔线 | `#9AAEB4` | `#555A58` |

实现时白天主题的次文字从稿件中的 `#65777D` 收紧为 `#596E75`，让 11–14px 的界面文字在 `#E8ECEB` 面板上达到 WCAG AA 对比度；其余核心色板按选稿落地。
